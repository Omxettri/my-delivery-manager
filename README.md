
# My Delivery Manager

A personal Android delivery management app for one driver.

## Features
- Manually add customer details.
- Save customer name, phone number and address.
- Manage daily delivery lists.
- Track pending and completed deliveries.
- Record delivery completion time.
- WhatsApp click-to-chat messaging.
- Editable WhatsApp message template.
- Google Maps navigation.
- Daily delivery history.
- CSV backup and restore.
- Optional fingerprint or phone PIN app lock.

## Privacy
Designed for personal use. Customer information should be kept private.

## Platform
Android

## Project Status
Source code prepared. Android APK build and physical-device testing are pending.
